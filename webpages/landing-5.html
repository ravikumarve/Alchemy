The Cognitive Pipeline

3 Specialized Agents orchestrated via LangGraph

Node 01: Active

The Archaeologist

The foundation of the pipeline. Acts as a Data Miner utilizing SemanticChunker and TableExtractor to parse raw unstructured.io data, isolating evergreen truths from outdated noise .

Time Budget: 80 Seconds
Step 1File Validation(5s)
Step 2Content Extraction(2s)
Step 3Semantic Analysis(30s)
Step 4Data Structuring(20s)
Step 5Quality Filtering(15s)
Step 6Metadata Enrichment(5s)
Step 7Package Generation(3s)
Step 1Receive Data Pack(5s)
Step 2Analyze Trends(15s)
Step 3Generate Hooks(20s)
Step 4Structure Narrative(25s)
Step 5Optimize Attention(10s)
Step 6Enhance Content(5s)
Step 7Package For Visionary(5s)
Node 02: Active

Trend-Jacker

The Contextualizer. It takes the structured truth from the Archaeologist and maps it to modern attention frameworks. It uses HookLibrary to generate viral entry points and restructures the narrative specifically for high-retention algorithms .

Time Budget: 90 Seconds
Node 03: Pending

The Visionary

The Media Architect. Analyzes the contextualized text to generate B-roll prompts, construct visual storyboards, and execute final asset packaging for production .

System Architecture

ALCHEMY is supported by a robust, modern stack capable of unattended execution and real-time monitoring.

  • ⬡
    Backend Infrastructure FastAPI handling 8 REST endpoints, SQLite for local storage, managed via Celery and Redis .
  • ⬡
    Command Dashboard Next.js 14+ App Router paired with shadcn/ui for real-time job tracking and package management .
  • ⬡
    Observability Prometheus Metrics tracking processing time and evergreen scores, visualized via Grafana .
Pipeline_Execution.py
from src.agents.archaeologist import ArchaeologistAgent
from src.agents.trend_jacker import TrendJackerAgent

# Initialize agents
archaeologist = ArchaeologistAgent()
trend_jacker = TrendJackerAgent()

# Process file through phase 1
arch_result = archaeologist.process_file("raw_ore/document.pdf")

if arch_result['success']:
    print(f"✓ Archaeologist completed in {arch_result['processing_time']:.2f}s")
    # Transmute into modern asset
    tj_result = trend_jacker.process(arch_result['package'])
